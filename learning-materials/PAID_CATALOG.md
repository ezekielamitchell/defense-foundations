## Pull contract

The 2026-09-04 provider-page check confirmed the then-nine selected links.
The September 12 source audit refreshed the P0 book/course routes and added
explicit backup/reference labels above; it did not re-audit every later-phase
source. These checks establish public catalog identity and scope, not
enrollment, full paid access, or completion. The Rust applications course is a fundamentals/HTTP-server
reference; do not treat its age or basic server exercise as current async,
security, or production-service training.

- Official documentation and primary sources remain authoritative.
- Open only the section that answers the current implementation question.
- Instruction is capped at `min(30 minutes, 25% of the existing block)`; backup
  sources replace a primary-source pull when useful, not stack on top of it.
- Apply the material in the same work block and run the acceptance command.
- Record the source, exact stop/resume point, artifact path, observed result, and
  blocker or `none`.
- Watching, completion percentages, certificates, and purchase state are not
  engineering evidence.
- Do not pre-schedule the catalog or create parallel course debt. No source
  update changes the active reset, reservation counts, gates or counters.

Founder, AI-startup, team-building, and government-contracting learning is
intentionally excluded from this engineering catalog. Aegis Nexus routes it as
bounded endr company support, at most one short issue-bound pull inside already
authorized company time.
