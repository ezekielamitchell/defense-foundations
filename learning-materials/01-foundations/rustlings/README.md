# Rustlings

**Source:** [rust-lang/rustlings](https://github.com/rust-lang/rustlings)  
**Cost:** free  
**Activation:** P0

## Scope

Complete the first 50 exercises using the current Rustlings ordering rather than a reset-era batch label. As of 2026-07-14, `.rustlings-state.txt` records `if2` as current and 15 completed exercises: `intro1`–`intro2`, `variables1`–`variables6`, `functions1`–`functions5`, `if1`, and `if3`.

Continue from `if2`. Do not restart “batch 1” or infer completion from an old weekly plan.

## Method

Read the compiler message, predict the fix, make the smallest change, and note recurring ownership/error patterns. Avoid looking at solutions until a deliberate debugging attempt has been documented.

## Evidence

Completion count plus short notes on ownership, borrowing, pattern matching, `Option`, and `Result` mistakes.
