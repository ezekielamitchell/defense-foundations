## Regular-week learning practice

The October 2 teaching plan uses 2 guided course hours and 4 bounded practice
hours on the same educational toy or fixture harness. Reproduce the guided
concept with changed input in one two-hour practice, then test an allowed case
and a refusal/failure in the other. Manual traces are enough before coding
prerequisites pass. Practice time is reassigned from existing endr morning
reservations, not added workload; first-week company setup exceptions follow
private active authority. Rust 8 hours and Python 6 hours already include their
Project 0 work. Actual classes, exams and deadlines persist without a blanket
finals reduction. The requested October 2–8 introduction is not activated by
this note.

Company M.A.L. remains separately governed in its current implementation
language. After supply-scheduling v0.2 acceptance, virtual data-center
maintenance becomes a second synthetic M.A.L. scenario, not another parallel
product. See the [project progression](../../curriculum/START_HERE.md#project-0-and-the-company-project).
