# P11 — Assurance, Security and Test Evaluation

**Curriculum v2 · prepared 2026-09-19**
**Status:** not started
**Route:** main route · **Prerequisites:** P10

No new dates or phase promotion follow from this preparation. Numeric IDs are
stable references; use prerequisites rather than completing every ID in order.

## Entry

Practices begin at P1; the complete integrated package requires P10 evidence.

## Learn

Requirements-to-tests traceability, hazard/threat reasoning, trust boundaries, least privilege, artifact provenance, dependency hygiene, failure containment, operator intervention and residual risk. Separate tests of accidental faults from adversarial robustness.

## Build

An assurance case for Flagship III: requirement, rationale, control, exact test/run, result and remaining limitation. Include deterministic bypass/refusal checks and a reproducible failure campaign.

## Acceptance evidence

Each major claimed control has observed tests; no unexplained authority expansion, stale approval or silent duplicate work. Tampered/untrusted inputs and restart/recovery are exercised. A missing result is explicitly unknown, not green.

## Source and scope

NIST AI RMF and official security/T&E guidance selected for the actual system. Doctrinal/legal documents are contextual sources to verify at use, not qualifications or legal conclusions.

**Defer:** Certification claims, exhaustive standards reading and untested security slogans. A curriculum gate grants no deployment authority.
