# Parallel Defense Curriculum

Python, Rust and AI-agent **basics** start together in the [first learning week](FOUNDATIONS_FAST_TRACK.md). Battlefield-AI context and warfare/law continue through bounded research and reading lanes. P0 remains the only active phase; later curriculum modules are not promoted by taking an introductory course. Exact dates and capacity belong to private Aegis authority.

Official provider pages support the source choices below. They are fits for the current beginner baseline and assurance-first goals, not guarantees of mastery. Account access, subscription coverage, enrollment and prices are unverified; no purchase is required. Vanderbilt labels its course beginner, but its full framework/API demonstrations go beyond a very beginner Python starting point; the first-week manual traces require no paid API.

Use one primary course **at a time** per track. The first week develops Python, Rust and agent basics; domain readings fit existing reading/research blocks and do not create extra courses. Parallel tracks do not mean collecting multiple courses on the same subject. Pause at the oldest unmet concept instead of following a calendar title past a prerequisite. Take short breaks inside the reserved studio.

## One-hour reading blocks

- **Python support:** [Python Crash Course, 3rd Edition — O’Reilly](https://www.oreilly.com/library/view/python-crash-course/9781098156664/). Match one Part I section to the current gap; read for 45 minutes, then predict and explain a changed input for 15 minutes.
- **Warfare concepts:** [MCDP 1, Warfighting — official Marine Corps edition](https://www.marines.mil/News/Publications/MCPEL/Electronic-Library-Display/Article/899837/mcdp-1/). Read one introductory section about uncertainty or friction; log one doctrine claim and contrast it with a legal rule from the Leiden course. This is critical source study, not an operational plan.
- **AI assurance:** [ICRC — AI and machine learning in armed conflict](https://www.icrc.org/en/document/artificial-intelligence-and-machine-learning-armed-conflict-human-centred-approach). Log one source claim, one limitation, and a human-control question. This is academic study, not individualized legal advice.
- **Paper reading:** use the privately selected paper in its existing one-hour reading reservation. Capture its question, method, result and one limitation; a skim or calendar event earns no implementation credit. Do not create a second daily paper quota here.
- **Later targeted reference:** [Chip Huyen — AI Engineering, O’Reilly](https://www.oreilly.com/library/view/ai-engineering/9781098166298/). The publisher labels it intermediate to advanced. Use a relevant evaluation chapter after basic Python and agent concepts; do not assign the full book to a complete beginner.

Alternate the doctrine and AI-assurance readings within the existing one-hour
reading blocks. For an optional official video explanation, use [MIT OpenCourseWare
6.100L Lecture 1 on YouTube](https://www.youtube.com/watch?v=xAcTmDO6NTI)
inside a Python studio: pause after the variables/types segment, predict a tiny
change, run it and explain the result. It is support, not a second Python course.
The [Princeton Paradoxes of War course](https://www.coursera.org/learn/war) is a
later **sequential** historical/social lens if the warfare/law track has room;
it is not a simultaneous second primary or a first-week obligation.

## Agent implementation reference

[Ed Donner — AI Engineer Agentic Track, Udemy](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/) is the selected follow-on implementation reference. Its framework projects are not additional weekly obligations. Begin them when you can explain functions, collections, imports, errors and the agent loop without copying. The introductory agent track starts now through explanations and small exercises; advanced implementation remains evidence-led.

## Evidence and progression

Each session ends with one artifact, an honest blocker if needed, and an exact resume point. For code, record working directory, command, exit code, observed output and changed files. Course attendance is not mastery. Keep agent/research evidence separate from Foundation gates and independently governed company work.

Project 0 remains the main curriculum build. Separate toy agent exercises do not authorize weapons, targeting, live systems or company deployment. The [competency pathway](COMPETENCY_PATHWAY.md) still governs later dependencies. Personal timing and capacity come only from the current private Aegis authority and its generated projection.

If a paid resource is unavailable, use an official free reference for that same concept and record the substitution. Do not buy a course merely to satisfy a calendar row.
