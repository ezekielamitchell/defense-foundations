# Personal project identity

The owner selected the Four Horses black v3 mark for personal-project identity.
This use identifies Defense Foundations as a personal project; it does not imply
company affiliation. Preserve all four units, their proportions and spacing.
Use black on light surfaces and ivory on dark surfaces.

[The selected master](four-horses-icon-black-v3.png) is a byte-identical copy of
the owner’s personal master. SHA-256:
`922306bb8d9c449aa579c1ab1e61bac9285a58b6198b0f3eddd4eace9c387707`.

The header, favicon, touch and installable-app PNGs are byte-identical copies
from the owner’s Four Horses Icon Pack v1. Those presentation exports preserve
the complete mark while removing excess transparent padding and scaling it as
one image. The light app tiles use black on ivory; the maskable icon includes
its own safe-area framing. No mark was redrawn for this application.
